Shisa: machine-traced vector candidates

Candidates, not marks. Everything on this page except the reference rows was produced by automated tracing (vtracer, potrace) of the 1024 px raster. None of it has been reviewed by a designer, and none of it replaces a file in marks/mark/ or marks/lockup/. Provenance and parameters: marks/PROVENANCE.md; rebuild with marks/candidates/tools/build.sh.

Each row is shown at 512, 128, 48, 32 and 16 CSS px. The one-colour marks use the ground's text colour (#faf6fa / #160d15); the one-colour favicon is shown in the colour its prefers-color-scheme rule would pick for that ground. On a high-DPI screen the small tiles get 2 to 3 device pixels per CSS pixel, so zoom the browser out, or look at renders/*-16.png, to see a true 16 px tab icon.
